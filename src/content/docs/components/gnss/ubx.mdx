The `ubx` [GNSS](/components/gnss/) platform reads u-blox receivers (u-blox 6, 7, M8, M9 and M10, for example the
NEO-6M) in their binary UBX protocol instead of NMEA. Compared with the [NMEA](/components/gnss/nmea/) platform it
adds:

- the receiver's own estimate of its horizontal and vertical accuracy in meters,
- time that is used only once the receiver knows the current GPS leap seconds, so the clock is never set a few
  seconds off right after a cold start,
- setting the measurement rate and the dynamic model of the receiver.

The receiver is configured on every start, so it needs no saved settings. The platform sets its output to UBX only
(NMEA is switched off), turns on the navigation messages it reads, and sets the rate and model. It reads the
receiver's firmware and protocol version first: from protocol 14.00 (u-blox 7 and later) it uses `NAV-PVT`, before
that (u-blox 6) the older `NAV-POSLLH`, `NAV-VELNED` and `NAV-SOL`. If the receiver stops sending data, for example
after a power cycle without a backup battery, the platform reports the values as unknown and configures it again.

A [UART bus](/components/uart) with both RX and TX is required, since the configuration is sent to the receiver. Set
`baud_rate` to the rate the receiver uses: 9600 for u-blox 6 and 7, 38400 for u-blox M10.

```yaml
# Example configuration entry
uart:
  rx_pin: GPIO16
  tx_pin: GPIO17
  baud_rate: 9600

gnss:
  - platform: ubx
    rate: 1Hz
    dynamic_model: automotive

sensor:
  - platform: gnss
    type: latitude
    name: "Latitude"
  - platform: gnss
    type: longitude
    name: "Longitude"
  - platform: gnss
    type: horizontal_accuracy
    name: "Horizontal Accuracy"
```

## Configuration variables

- **rate** (*Optional*, frequency): How often the receiver computes a solution, between `0.1Hz` and `25Hz`. u-blox 6
  receivers reach up to 5 Hz, later ones 10 Hz or more; a receiver that cannot use the rate rejects it and keeps its
  own. At 9600 baud, rates above about 3 Hz leave too little time on the UART for the messages. Defaults to `1Hz`.
- **dynamic_model** (*Optional*): The motion the receiver should expect, which filters its position and speed. One of
  `portable` (the receiver's default), `stationary`, `pedestrian`, `automotive`, `sea`, `airborne_1g`,
  `airborne_2g` or `airborne_4g`. Not set by default, so the receiver keeps its own.
- **uart_id** (*Optional*, [ID](/guides/configuration-types/#id)): The UART bus of the receiver. Only needed when
  there is more than one.
- All options from the [GNSS base configuration](/components/gnss/#base-configuration).

The firmware, hardware and protocol version of the receiver are logged when ESPHome prints its configuration.
